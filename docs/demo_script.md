# Demo(about 5 minutes)

1. Show the GitHub repository: branches, merged pull requests, folder structure.
2. Build and start the program.
3. Option 1 (normal), option 2, option 3: every place is NORMAL. Riverside scores highest (18.7) because it is the most flood-prone place.
4. Option 1 (flood), option 2, option 3: Riverside is CRITICAL (81.3), the rest are WARNING. The sudden water rise is shown.
5. Option 6 for HillRoad, severity 3, minutes 1, five times: each report is accepted and the count rises from 1 to 5. Then once more with minutes 0: it is rejected as a duplicate. Option 2 and 3: HillRoad becomes CRITICAL (81.3).
6. Option 4: alerts come out in priority order. HillRoad first (priority 400, confidence 100%), then Riverside (340, confidence 40%), then the warnings.
7. Option 8, place Riverside: route to SchoolShelter (8 km).
8. Option 7, road 5 to 6 (BridgeEast to SchoolShelter): the route is recalculated to HillShelter (11 km).
9. Option 7, road 4 to 5 (BridgeWest to BridgeEast, the bridge): no safe route.
10. Option 9 and 10: save the report and the state.
11. Each member explains their module in 30 seconds.
12. Show the C++ side: classes, inheritance, polymorphism, exception for a missing file.
