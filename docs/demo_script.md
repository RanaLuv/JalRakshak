# Demo Script (about 5 minutes)

1. Show the GitHub repository: branches, merged pull requests, folder structure.
2. Build and start the program.
3. Option 1 (normal), option 2, option 3: all places NORMAL.
4. Option 1 (flood), option 2, option 3: ranking and the main factor. Option 4: alerts in priority order.
5. Option 6 twice for the same place: the second report is a duplicate.
6. Option 8: route. Option 7: block the bridge, the route is recalculated. Block the hill road: no route.
7. Option 9 and 10: save the report and the state.
8. Each member explains their module in 30 seconds.
9. Show the C++ side: classes, inheritance, polymorphism, exception for a missing file.
